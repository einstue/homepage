# Personal homepage

This is a plain static site: open `index.html` in a browser, or publish this folder with GitHub Pages.

## Add an essay

1. Put the PDF in `Writings/Essays`, for example `Writings/Essays/black-holes.pdf`.
2. In `index.html` and/or `documents.html`, copy the existing essay entry and change its link to `href="Writings/Essays/black-holes.pdf"`.
3. Replace its title, course/year, short description, and PDF page count.

The first entry is stored locally in `Writings/Essays`. You can keep using external links or place later PDFs in the same folder.
